## Deployment and remaining gates

Set `AZURE_TTS_KEY`, `AZURE_TTS_REGION`, `AZURE_TRANSLATOR_KEY` and `AZURE_TRANSLATOR_REGION` on the backend before the coordinated frontend/backend deployment. Next requires `API_URL`. With embedded workers disabled, supervise an attachment role for queued tutor uploads; keep API/worker role settings consistent. Do not enable Battle's Redis adapter or change quiz-only mode implicitly.

Three existing local speech settings were moved from ignored `frontend/.env.local` into ignored `backend/.env`, preserving other settings and existing backend values. No credentials were printed or committed. Restart the local backend to load them. Remote deployment settings still need the coordinated transfer described above.

Live Azure/B2/Firebase provider calls, GitHub Actions execution, external worker supervision, staging multi-instance load and production canary checks have not been performed. No production-readiness claim follows from local tests. Full backend TypeScript conversion, replacement of the existing queue topology, and removal of old image compatibility remain the audit's incremental/conditional follow-up work.
