# Archived prototype

These CommonJS modules are not imported or mounted by `backend/index.js` or the frontend. They used the root JSON database and preceded the MongoDB question services and `/api/adaptive-quiz` implementation.

The directory retains the original relative structure for historical reference. It is not an npm workspace or a supported server. The active upload UI is `/admin/upload` in the frontend. Do not mount these routes alongside the production ESM backend.
