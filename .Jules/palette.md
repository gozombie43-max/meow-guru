## 2024-10-24 - Accessibility improvements for Dashboard Tabs\n**Learning:** The dashboard used pill and segment buttons for navigation without semantic tab roles, making them confusing for screen readers. Using Playwright to bypass the auth screen required injecting localStorage, but the original script had issues with mobile/desktop responsiveness hiding the elements.\n**Action:** Add semantic ARIA roles (tablist, tab, aria-selected) to all custom tab implementations. Ensure Playwright tests account for responsive rendering when looking for elements.
